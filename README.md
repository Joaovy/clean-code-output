# 📘 Clean Code Lab

Este repositório foi criado para aplicar, na prática, os princípios apresentados no livro *Clean Code*, de Robert C. Martin.

O objetivo não é apenas ler o livro, mas desenvolver disciplina na escrita de código claro, simples e sustentável. A proposta é evoluir um mesmo domínio ao longo dos capítulos, refatorando continuamente e aplicando os conceitos aprendidos.

Clean Code propõe que qualidade não é um detalhe opcional, mas uma responsabilidade profissional. O livro aborda temas como nomeação significativa, funções pequenas e focadas, responsabilidade única, tratamento adequado de erros, organização, testes e redução de acoplamento.

---

## Sobre o Projeto

O repositório funciona como um laboratório de estudo contínuo.  
Um mesmo domínio será utilizado como base para aplicar os conceitos do livro, permitindo evolução progressiva do código ao longo do aprendizado.

O código pode começar propositalmente imperfeito, com o objetivo de possibilitar refatorações orientadas pelos princípios estudados.

Espera-se que, ao final do processo, o projeto reflita:

- Melhor organização estrutural
- Redução de acoplamento
- Maior clareza e legibilidade
- Separação adequada de responsabilidades
- Código preparado para manutenção e evolução

A intenção não é apenas produzir código funcional, mas desenvolver maturidade técnica na construção de software.
